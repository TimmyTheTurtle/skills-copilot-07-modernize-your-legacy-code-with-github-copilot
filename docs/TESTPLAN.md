# COBOL Account Management System Test Plan

This test plan captures the current business behavior implemented by `main.cob`, `operations.cob`, and `data.cob`. Execute the cases from a fresh application run unless the pre-conditions say otherwise. Record the observed output in **Actual Result**, then mark **Status** as `Pass` or `Fail`.

## Execution Notes

- Start a fresh process for cases that depend on the default balance.
- Cases TC-003 through TC-014 can be combined in one session only when each case's starting balance is adjusted to match its pre-condition.
- The current implementation stores the balance in working storage only; it does not persist the balance across application processes or to a file/database.
- Amounts are displayed with leading zeroes and two decimal places because of the COBOL picture clauses.
